## Объём

## Проверка кейса

- Русская и английская страницы проверены локально на ширинах 390 и 1440 пикселей: горизонтального переполнения нет, основной левый отступ на мобильном — 20 пикселей, на desktop контент выровнен по общей сетке.
- Все изображения после прокрутки загрузились и имеют ненулевые естественные размеры; ошибок выполнения в браузере не зафиксировано.
- Полностраничные контрольные снимки сохранены в `docs/audits/chainya-case-qa/` для RU/EN и mobile/desktop.
- Социальные карточки RU/EN пересобраны из актуального публичного экрана и визуально проверены в размере 1200×630. Локальная среда не содержит Pillow, поэтому воспроизводимый Python-генератор обновлён, но его повторный запуск в этой среде не использовался: готовые карточки получены тем же макетом через локальный браузер.
- Полная автоматическая проверка сайта, launch-check, проверка Git diff и аудит production-зависимостей выполняются перед публикацией; их итог фиксируется в журнале публикации и GitHub Actions.
- Послепубликационная проверка выявила слишком высокий первый экран: при 1280 и 390 пикселях основная кнопка оказывалась ниже видимой области. Размер заголовка, вертикальные интервалы и высота мобильного изображения уменьшены без изменения текста; CTA снова попадает в первый экран.
- Отдельно проверена карточка проекта в общем портфолио. Схематичная иллюстрация заменена настоящим кадром каталога с явной подписью «живой каталог»; движение ограничено одним появлением при прокрутке и спокойным увеличением при наведении.
