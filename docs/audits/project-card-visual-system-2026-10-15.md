# Визуальная система карточек проектов — 15 октября 2026

## Результат

Все девять карточек `projects.html` и `en/projects.html` используют проектные изображения, уже хранившиеся в репозитории. Низкодетальные CSS-схемы больше не являются главным изображением карточек. Новые растровые файлы не создавались и размер репозитория этой доработкой не увеличен.

## Поведение

- Изображение остаётся декоративным: смысл и статус продублированы обычным текстом карточки.
- Русская и английская страницы получают соответствующие локализованные обложки.
- При наведении кадр увеличивается на пять процентов; карточка появляется один раз при попадании в область просмотра.
- При `prefers-reduced-motion: reduce` переход изображения отключается.
- На ширине 390 пикселей высота изображения составляет 154 пикселя; горизонтального переполнения нет.

## Проверка

- RU и EN: 1280×720.
- RU: 390×844.
- Все девять фоновых изображений разрешились в локальные URL; сетевых и консольных ошибок не обнаружено.
- `npm test`, `npm run launch:check`, production audit и `git diff --check` выполняются перед публикацией.
