Everyday owner operations

Change the site without a developer

  • Three-language copy, images, contacts, documents and section order.

How the system is connected

The architecture separates the public storefront, business-rule validation, storage and external channels.

01 · interface

Three languages

02 · server

FastAPI

Validates prices, stock, booking slots, access rights and status transitions.

03 · data

SQLite

One active writer, atomic updates, publication history and snapshots.

04 · integrations

Bank, delivery, Telegram

Separate adapters for payment, delivery quotes, sign-in and notifications.

Migration without a second writer

On 13 October 2026 the live site and state moved to a separate Sprinthost X-4 account. This is shared hosting, not a dedicated VPS; the bot is hosted separately.

What this proves: transfer integrity, HTTPS, key-page availability and code rollback. What it does not prove: a real payment, fiscal receipt, delivered message or business uplift. Write operations were deliberately excluded from that acceptance check.
